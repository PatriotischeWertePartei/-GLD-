UNSER CAFÉ
Ein Ort zum Durchatmen
Das Café Moorbad liegt idyllisch an der Schwaaner Chaussee inmitten des historischen Heilbades Bad Doberan. Mit einem herrlichen Ausblick ins Grüne bieten wir Ihnen hausgemachte Kuchen, frische Waffeln und aromatischen Kaffee.
Serviert von einem herzlichen Team – täglich von 14:00 bis 17:30 Uhr. Kommen Sie einfach vorbei.
